# 以问题驱动的工业视觉项目、人才与知识管理平台

## 产品定位

团队成员只需要正常完成工作：**记录问题、反馈进展、更新解决办法、上传图片/视频/文件、验证并关闭问题**。
系统在后台自动完成：

- 项目状态与延期管理
- 问题全过程留痕
- 问题复盘草稿
- 项目复盘草稿
- 工业视觉案例卡沉淀
- Agent/RAG 可用的结构化知识输出
- 基于问题的管理反馈、协作结论、人员成长记录与周报草稿

核心原则：**项目管理、复盘、知识沉淀都应成为日常解决问题的副产品，而不是额外工作。**

## 技术栈

- FastAPI
- SQLAlchemy
- SQLite + WAL
- Vue 3 + Vite（前端源码在 `frontend/`，构建产物在 `app/static/`）
- 本地文件系统保存图片、视频和附件
- 本地账户登录、会话 Cookie 与角色权限

面向 10 人左右局域网团队的第一阶段原型。数据库访问层已隔离，未来可迁移 PostgreSQL。

## Windows 快速启动

1. 安装 Python 3.11+
2. 双击 `setup_and_start.bat`
3. 浏览器打开 `http://127.0.0.1:8765/`（不要打开 `0.0.0.0`）
4. 局域网成员访问 `http://服务器IP:8765/`

首次启动会自动创建默认用户 `管理员`。在服务器本机打开页面，先设置管理员密码（至少 12 个字符）。然后用“用户与角色”页面为其他成员分配角色和初始密码；原有用户及项目数据会保留，原有用户在设置密码前无法登录。设置管理员密码必须在服务器本机完成。

内置角色：管理员、部门负责人、团队主管、项目负责人、技术负责人、团队成员、专家、知识管理员、只读成员。一个用户可以有多条角色授权，每条授权可限定本人、项目、团队、部门或全局范围。管理员可添加和停用用户、重置密码、配置组织和授权，也可创建自定义角色；成员登录后可自行修改密码。停用用户保留历史记录。登录会话有效期为 12 小时；修改密码或停用账户会让旧会话失效。

在“问题 → 沟通反馈”中可以发表认可、建议、追问、协助四种反馈，并用事实、判断、决定、承诺记录关键沟通结论。项目详情支持成员和里程碑。“人员与沟通”显示有来源的工作负荷、协作贡献、沟通建议、能力证据、1 对 1 纪要、成长行动、提醒和本人周报。能力证据与管理建议是规则生成的待确认信息，不作为自动绩效评价。详见 [实施方案](DEVELOPMENT_PLAN.md)。

启动脚本仍使用 HTTP。面向非受信任网络部署时，请先通过 HTTPS 反向代理提供访问，避免登录密码在传输途中暴露。

仓库已包含构建好的前端页面，普通部署仍只需 Python。修改前端时需要 Node.js 22.18+ 或 24.12+：

```bash
cd frontend
npm ci
npm run build
```

开发时可运行 `npm run dev`，Vite 会将 `/api` 和 `/uploads` 代理到本机 8765 端口的 FastAPI。构建会更新 `app/static/`，提交前端改动时需同时提交构建产物。可设置 `VISION_PORT` 环境变量自定义后端端口，启动脚本和 Vite 代理都会使用它。

## 日常使用

普通成员主要只做四件事：

1. **新增问题**：项目、类型、描述、优先级、Owner、计划关闭时间；图片/视频可直接上传。
2. **随手反馈**：像聊天一样补充进展，可带图片、视频、日志、Excel 等。
3. **更新解决办法 / 验证结果**：每次尝试都会作为事件保留，失败方案不会被最终方案覆盖。
4. **关闭问题**：系统自动记录实际关闭时间、延期情况并更新复盘与知识案例。

## 备份

运行：

```bash
python scripts/backup.py
```

会使用 SQLite 在线备份机制生成到 `data/backups/`。存在图片、视频或私密反馈附件时，同时生成同名 `.attachments.zip` 文件；恢复时应将数据库和附件一起恢复。

## 测试

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

## 关键目录

- `app/` 后端与前端构建产物
- `frontend/` Vue 源码与 Vite 配置
- `data/vision_knowledge.db` 数据库
- `data/uploads/` 图片、视频、文件
- `data/backups/` 备份
- `tests/` 自动化测试
- `DESIGN.md` 详细设计
- `ACCEPTANCE.md` 用户验收清单
- `VALIDATION.md` 当前版本验证结果
